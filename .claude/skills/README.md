## Cambios respecto al original

- Si dos skills se llamaban igual, la segunda lleva delante el nombre de su repo (`ecc-`, `daymade-`).
- Llevan prefijo para no confundirse con nombres genéricos: todas las de claude-mem (`mem-`; su `babysit` choca con la convención de Claude Code para vigilar PRs), las de supabase (`supabase-`, son para trabajar en el propio Supabase), las secundarias de agent-browser (`agent-browser-`) y las de codegraph (`codegraph-`).
- `ui-ux-pro-max` y las de claude-seo: rutas `${CLAUDE_PLUGIN_ROOT}/…` cambiadas a `.claude/skills/…`; los scripts de claude-seo están en `seo/scripts/` (`bash .claude/skills/seo/scripts/claude-seo doctor`).
- superpowers: quitado el prefijo `superpowers:` de las referencias internas.

## No incluidas

- **gstack** (garrytan/gstack): sus skills dependen de programas propios en `~/.claude/skills/gstack/bin/` que compila su instalador con Bun. Instálalo en tu ordenador:
  `git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup`
- Traducciones y copias para otros agentes (ECC `docs/*`, `.kiro`, `.agents`, `pi/`; `everything-claude-code-es`) y las de WorldFlowAI/everything-claude-code, que es una versión antigua de ECC.
- `project-guidelines-example`: plantilla sin cabecera de skill.
- graphify, headroom y claude-token-efficient no traen skills (son herramientas / un CLAUDE.md).

## Requisitos de algunas

- claude-mem (`mem-*`) necesita el servicio de claude-mem instalado; strix, agent-browser y playwright-cli necesitan sus CLIs; claude-seo usa Python.
